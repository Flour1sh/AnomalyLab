## 操作路径
1. 保留完整 Windows 目录，双击 AnomalyLab.exe 正常冷启动，点击开始。入口整备显示永久余额（初次0）、四商品和等级；↑↓选择，Enter购买，E开始。
2. WASD移动、鼠标观察；1切换三仪器、2装备枪（尚无射击）；对准300cm内箱子按住Q一秒。每种默认3次，取消不扣费，已有结果免费复看。每轮三箱，只能开一个。
3. A偏低风险、B中风险、C高风险高收益；Unknown仍可能危险。E开箱，E拾取；背包默认4格，升级5格，满格物品留地。
4. 开箱后1继续、2仅选择返程；沿绿线实际走回入口按E兑现。没有入口E确认就没有永久收益；两次收容后必须返程。
5. 撤离所得购买电池/精度/背包或下一局的一次性诱饵。重新启动第二局核对剩余扫描次数、金额范围/概率等级和第五格；F在脚下放诱饵，最多1个，对观察者无效。
6. C区可能自然遇到观察者（不保证每局）；一秒青色预警。20m内正视眼部停步，墙体/背向会接近；累计注视4秒后红眼1.25秒，保持距离并继续移动，红眼后重新注视。尝试返回入口的路线，确认提示是否看得懂、逃生是否可行。
7. 携货死亡，核对本局物品丢失、永久余额与升级保持；R重开。退出程序重新启动，核对恢复。
8. 分别尝试低风险/高收益/随机打法，记录实际局长；3–5分钟是待调目标，无倒计时强迫结束。
